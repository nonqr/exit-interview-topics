# Публикация на Hugging Face Spaces

Сервис публикуется как **Docker Space** на Hugging Face: бесплатный тариф (CPU basic) даёт 2 ядра и
16 ГБ памяти, этого хватает для модели Qwen3-Embedding-4B. Hugging Face сам собирает Docker-образ из
файлов проекта и выдаёт постоянную ссылку вида `https://huggingface.co/spaces/<пользователь>/<имя>`.

## Что уже подготовлено

| Файл | Зачем |
|---|---|
| `Dockerfile` | Образ сервиса: PyTorch для CPU, зависимости, модели скачиваются при сборке |
| `requirements-app.txt` | Зависимости сервиса с точными версиями (проверены вместе) |
| `src/app/warmup.py` | При сборке скачивает модели, считает эмбеддинги демо-датасета и прогоняет пробный анализ во всех режимах |
| `deploy/space_README.md` | Карточка Space: настройки (`sdk: docker`, порт 8501) и описание |
| `deploy/deploy_space.py` | Собирает нужные файлы и загружает их на Space |
| `.github/workflows/deploy-space.yml` | Автоматическая публикация после каждого изменения в `main` |


## Шаг 1. Аккаунт и токен (один раз)

1. Зарегистрируйтесь на https://huggingface.co.
2. Откройте **Settings → Access Tokens → Create new token**, тип **Write**. Скопируйте токен (`hf_...`).
   Токен — это пароль: не публикуйте его и не коммитьте в репозиторий.

## Шаг 2. Первая публикация

С компьютера, где склонирован репозиторий:

```bash
pip install "huggingface_hub>=1.0"
```

```bash
HF_TOKEN=hf_ваш_токен python deploy/deploy_space.py <ваш_логин_на_HF>/exit-interview-topics
```

В Windows (PowerShell):

```powershell
$env:HF_TOKEN="hf_ваш_токен"; python deploy/deploy_space.py <ваш_логин_на_HF>/exit-interview-topics
```

Скрипт создаст Space, если его нет, и загрузит файлы. Дальше Hugging Face собирает образ:
статус виден на странице Space во вкладке **Logs**. Первая сборка занимает 15–30 минут — основное
время уходит на скачивание моделей (~10 ГБ).

## Шаг 3. Автоматическая публикация из GitHub (по желанию)

Чтобы сервис обновлялся сам после каждого влитого pull request:

1. В репозитории на GitHub: **Settings → Secrets and variables → Actions**.
2. Вкладка **Secrets** → **New repository secret**: имя `HF_TOKEN`, значение — токен с шага 1.
3. Вкладка **Variables** → **New repository variable**: имя `HF_SPACE`, значение `<ваш_логин_на_HF>/exit-interview-topics`.

После этого каждое изменение в `main` публикуется автоматически (вкладка **Actions** на GitHub).
Запустить публикацию вручную: **Actions → Публикация на Hugging Face Spaces → Run workflow**.

## Что нужно знать о бесплатном тарифе

- **Засыпание.** Space засыпает после 48 часов без посетителей. Первый заход после этого будит его
  1–2 минуты. Перед защитой откройте ссылку заранее.
- **Скорость.** На 2 ядрах точный режим считает новый файл из ~500 ответов несколько минут. Демо-датасет
  посчитан заранее при сборке и открывается за секунды. Для быстрой демонстрации своих файлов есть
  быстрый режим (e5-large-instruct).
- **Данные.** Файлы, загруженные пользователями, не сохраняются на диск Space: они живут только в
  памяти, пока открыта сессия. Для реальных HR-данных публичный Space не подходит — сервис нужно
  разворачивать внутри компании (тот же Docker-образ).

## Запуск через Docker без Hugging Face

```bash
docker build -t exit-interview-topics .
docker run -p 8501:8501 exit-interview-topics
```

Сборка без предварительной загрузки моделей (быстрее, модели скачаются при первом анализе):

```bash
docker build --build-arg PRELOAD=0 -t exit-interview-topics .
```
