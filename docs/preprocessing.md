# Предобработка текста

Код: `src/preprocessing/`, тесты: `tests/test_preprocessing.py`.

```bash
# демонстрация: отчёт и примеры «было → стало», результат в data/processed/
python -m src.preprocessing data/raw/exit_interviews.xlsx

# сравнение вариантов предобработки по метрикам качества
python -m src.evaluation.preprocessing_report
```

## Два уровня обработки

Разным моделям нужен разный текст, поэтому обработка разделена на два уровня.

| | Лёгкая очистка `normalize_text()` | Полная обработка `TextPreprocessor.tokens()` |
|---|---|---|
| Для чего | эмбеддинги e5 | LDA, NMF, ключевые слова тем |
| Регистр и формы слов | сохраняются | нижний регистр, начальная форма |
| Служебные слова | сохраняются | удаляются |
| Результат | `Начальник откровенно хамит!` | `['начальник', 'откровенно', 'хамить']` |

Нейросетевая модель сама понимает формы слов и контекст, а лемматизация и удаление слов
только лишают её информации. Классическим моделям наоборот нужен «мешок слов», где
«зарплата», «зарплаты» и «зарплату» — одно слово.

## Шаги полной обработки

Пример: `"  Зп маленькая, а обязанностей добавили в два раза больше!!! 😔"`

| Шаг | Что делаем | Зачем | Результат |
|---|---|---|---|
| 1. Очистка | убираем эмодзи, ссылки, почту, телефоны, повторы «!!!», лишние пробелы | мусор и персональные данные | `Зп маленькая, а обязанностей добавили в два раза больше!` |
| 2. Регистр | всё в нижний регистр | «ЗАРПЛАТА» и «зарплата» — одно слово | `зп маленькая, а обязанностей…` |
| 3. Сочетания | «з/п», «заработная плата» → «зарплата» | склеить синонимы до токенизации | |
| 4. Токенизация | выделяем слова регулярным выражением, дефис внутри слова сохраняем | отделить слова от знаков препинания | `зп` `маленькая` `а` `обязанностей` `добавили` `в` `два` `раза` `больше` |
| 5. Лемматизация | pymorphy3 приводит слово к начальной форме, «ё» → «е» | разные формы одного слова считаются одним словом | `зп` `маленький` `а` `обязанность` `добавить` `в` `два` `раз` `большой` |
| 6. Исправления | словарь `lemma_overrides.txt`: «зп» → «зарплата», «тимлида» → «тимлид» | сленг, сокращения, ошибки pymorphy | `зарплата` … |
| 7. Части речи | оставляем существительные, прилагательные, глаголы, наречия; убираем предлоги, союзы, частицы, местоимения, сравнительную степень | служебные слова не несут смысла | `зарплата` `маленький` `обязанность` `добавить` `два` `раз` |
| 8. Стоп-слова | общие (`stopwords_ru.txt`) и доменные (`stopwords_domain.txt`) | слова, которые есть в ответах про любую причину | `зарплата` `маленький` `обязанность` `добавить` |

**Лемматизация** — приведение слова к словарной (начальной) форме: «платят» → «платить»,
«переработки» → «переработка». В отличие от стемминга, который просто отрезает окончание
(«переработк»), лемматизация использует словарь и даёт настоящее слово. Для русского языка с
его богатой морфологией это особенно важно: у одного существительного до 12 форм.

**pymorphy3** — морфологический анализатор на основе словаря OpenCorpora. Для каждого слова он
выдаёт возможные разборы с вероятностями, мы берём самый вероятный. Это продолжение pymorphy2:
pymorphy2 не работает на Python 3.11 и новее.

**Доменные стоп-слова** — слова, которые встречаются в ответах про любую причину увольнения:
«работа», «компания», «уйти», «причина». В обычных текстах они значимы, но здесь не помогают
отличить одну тему от другой.

## Фильтрация строк

- **Бессмысленные ответы.** Отбрасываем ответ, если в нём нет букв («-», «???»), если он
  совпадает с типичным пустым ответом («нет», «без комментариев», «всё хорошо») или если после
  удаления стоп-слов не остаётся ни одного слова («просто решил уйти»). Список типичных пустых
  ответов составлен заранее по смыслу, а не скопирован из датасета, иначе оценка была бы нечестной.
- **Дубли.** Строка считается дублем, только если совпадает во всех колонках, кроме номера анкеты:
  так выглядит повторная отправка формы. Одинаковый ответ «мало платят» от двух разных людей — не
  дубль, это два голоса за одну причину.

## Решения, которые мы проверили на метриках

- **Склейка отрицаний** (`join_negations`): «не платят» → `не_платить`. Сохраняет смысл, но
  увеличивает словарь и делает его разреженнее. На наших данных результат смешанный, поэтому по
  умолчанию выключено.
- **Фильтр по частям речи** дал самый большой прирост качества (см. ниже).

## Результаты

Фильтр пустых ответов по эталонным меткам: найдено 23 пустых ответа, все 23 верно
(precision 1.00), пропущено 2 из 25 (recall 0.92): «Удачи компании» и «всё устраивало просто пора».
Ни один содержательный ответ не выброшен. Все 6 дублей найдены.

Влияние шагов на качество тем (10 тем, 459 ответов):

| Вариант | NMF ARI | NMF c_v | LDA ARI | LDA c_v | LDA разнообразие | Словарь |
|---|---|---|---|---|---|---|
| Случайное разбиение | 0.000 | — | 0.000 | — | — | — |
| 1. Только лемматизация | 0.035 | 0.37 | 0.018 | 0.31 | 0.56 | 1215 |
| 2. + фильтр частей речи | 0.093 | 0.39 | 0.014 | 0.38 | 0.69 | 1164 |
| 3. + доменные стоп-слова (по умолчанию) | **0.098** | **0.42** | 0.025 | **0.47** | **0.83** | 1136 |
| 4. + склейка отрицаний | 0.090 | 0.40 | 0.042 | 0.43 | 0.79 | 1173 |

Выводы:

- Предобработка почти утроила совпадение NMF с эталоном (ARI 0.035 → 0.098). У LDA связность тем
  выросла с 0.31 до 0.47, а разнообразие тем — с 0.56 до 0.83: темы перестали повторять друг друга.
- При этом абсолютные значения остаются низкими, а LDA по-прежнему неустойчива (устойчивость
  около 0.02). Ограничение уже не в очистке, а в коротких ответах (в среднем 5 лемм) и в модели.
  Это задача спринта 3: подбор числа тем и параметров, эмбеддинги e5.
