# Причины увольнений по экзит-интервью

Загрузите выгрузку анкет экзит-интервью (CSV или Excel) — сервис очистит ответы, найдёт основные
причины увольнения и покажет, в каких отделах и когда они встречаются чаще.

Можно сразу попробовать на демо-датасете из 490 синтетических анкет.

- Модель: `Qwen/Qwen3-Embedding-4B` с инструкцией «определи причину увольнения» + KMeans.
- На синтетическом датасете с известными причинами: ARI 0.68, macro-F1 0.83.

Код, документация и описание экспериментов — в репозитории проекта на GitHub.
